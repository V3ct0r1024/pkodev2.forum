# Архив форума serverdev.net

![](images/0.png)

Зарубежный форум по тематике разработки и администрированию серверов Пиратии (Tales of Pirates, Pirate King Online), который работал в 2009 — 2015 годах. На форуме было представлено очень много полезной информации и материалов на английском языке. В данной теме выкладываем дамп serverdev.net в виде набора HTML-страниц.

В архиве "**Forum Archive of serverdev.net.zip**" находятся две версии сайта:

* Версия форума 2009 — 2012 годов:
  ```
  Откройте файл ".\Serverdev.net (2009 - 2012)\index.php.htm"
  ```

* Версия форума 2012 — 2015 годов:
  ```
  Откройте файл ".\Serverdev.net 2 (2012 - 2015)\index.htm"
  ```
